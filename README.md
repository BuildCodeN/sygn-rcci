# SYGN — Système National de Gestion (version d'essai)

Application web du Renouveau Charismatique de Côte d'Ivoire : membres, activités, contrôle des présences
par pièce d'identité (lecture par caméra), statistiques, module Intercession.

**Version d'essai publique — aucune donnée réelle.** Les données restent dans le navigateur de chaque appareil
(aucun serveur). Pour essayer : ouvrir l'adresse avec `?demo=1`, choisir un compte de démonstration, puis
« Charger la démonstration » sur le tableau de bord (personnes fictives).
